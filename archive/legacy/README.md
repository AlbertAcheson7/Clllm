# Legacy archive

Code is placed here when it is no longer part of an active execution path but
is still useful for comparison or recovery.

Rules:

- Do not import archived code from active projects.
- Each archived implementation documents its former location and replacement.
- Preserve code history; do not put datasets, model weights, checkpoints, or
  full experiment outputs here.
- Remove an archive only after its replacement has been reproduced and the Git
  history has been verified.
